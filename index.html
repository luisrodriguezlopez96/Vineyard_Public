Una herramienta nacida en la explotación

El viñedo se gestiona en el campo. Los datos, también.

Una aplicación híbrida para tener juntas la cartografía de las fincas, la evolución de cada campaña, la agronomía y los informes. El escritorio es el núcleo de gestión; la PWA móvil acerca los datos al trabajo diario.

Arquitectura y stack

Local por diseño.
Conectada cuando hace falta.

El escritorio mantiene la base de datos de la explotación. Una API local permite el intercambio con la PWA; los servicios externos se utilizan para consultas concretas, como cartografía, elevación o meteorología.

01 · Núcleo localPython 3.13, Tkinter/CustomTkinter y SQLite para la aplicación de escritorio y los datos de explotación.
02 · API de la explotaciónFlask ofrece endpoints REST/JSON al móvil y permite el intercambio dentro de la red local.
03 · Experiencia móvilPWA con HTML, CSS y JavaScript, pensada para uso móvil y captura de datos sin conexión.

Componentes principales

Tecnología elegida para el trabajo diario.

Una combinación pragmática de herramientas de escritorio, datos locales, cartografía y visualización; sin hacer de la nube un requisito para la base de la aplicación.
