# Publicación de Gestión Vitícola Public

La web usa `index.html` como entrada y todos los recursos visuales están en `assets/`. El sitio es estático, sin dependencias de servicios externos para renderizar.

## GitHub Pages

En GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.

URL prevista: https://luisrodriguezlopez96.github.io/Vineyard_Public/

## Seguridad

Este repositorio contiene exclusivamente material de presentación. No copiar aquí el código de `Vineyard` o `Vineyard_App`, bases de datos, logs, archivos de configuración ni copias de seguridad.
